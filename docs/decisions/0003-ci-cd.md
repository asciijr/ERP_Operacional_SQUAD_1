# 0003 · CI e CD

- **Data:** 2026-11-12
- **Status:** CI aceita · CD parcial (deploy aguarda DP13)
- **Responsável:** Ilton Batista

## Contexto
O guia define o `ci.yml` de referência. Hospedagem e CD estão pendentes (DP13).

## Decisão
**CI (`.github/workflows/ci.yml`)**, em todo PR para `develop` e `main`:
- jobs do guia: `branch-guard`, `frontend`, `backend-node` (lint, typecheck, testes, build);
- complementos: `conventions` (título do PR e nome de branch), `review-summary` (resumo para o revisor), checagem de migrations no `backend-node` com PostgreSQL de serviço, e `docker` (imagens de produção constroem).

**CD (`.github/workflows/release.yml`)**, ao criar tag `vX.Y.Z` na `main`:
- publica `erp-operacional-backend` e `erp-operacional-frontend` no GitHub Container Registry;
- cria a GitHub Release com notas automáticas.

**Deploy em servidor:** não implementado até a DP13 definir a hospedagem. As imagens publicadas já servem de artefato para qualquer opção.
